# Space Shooter

A 2D game developed in **C# using MonoGame**.

## Description

Do you know about the game [Space Invader](https://fr.wikipedia.org/wiki/Space_Invaders) from 1978? If yes, you will like this. It will by a modern version of the game, or i will try to make it as close as possible.

Explain the objective, gameplay, and main mechanics.
The objectives are to create a game close to, if not identical, to [Space Invader](https://fr.wikipedia.org/wiki/Space_Invaders).

I will go for the base but add more features if needed or wanted.

## Features

* Player movement
* Shooting / combat
* Enemies
* Collision system
* Score system
* Health system
* Sound effects and music
* Main menu
* Settings

## Installation

Clone the repository:

```bash
git clone https://github.com/Mommy-Of-Light/SpaceShooter.git
```

Enter the project directory:

```bash
cd SpaceShooter
```

Open the `.sln` file with Visual Studio.

Restore the required dependencies and build the project.

## Running the Game

Run the project from Visual Studio using:

```text
F5
```

or:

```text
Ctrl + F5
```

## Controls

| Key      | Action       |
| -------- | ------------ |
| `W`      | Move Up      |
| `A`      | Move Left    |
| `S`      | Move Down    |
| `D`      | Move Right   |
| `Space`  | Shoot        |
| `Escape` | Pause / Menu |
